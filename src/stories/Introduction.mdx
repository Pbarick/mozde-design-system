# Mozde Design System

A React and Tailwind component library for a corporate newsroom and intranet portal.
Mozde is a fictional brand name used for portfolio purposes.

## How to use this Storybook

- **Components** lists every building block. Use the Controls panel to change props live, and the Docs tab for a description and full prop table.
- **Pages** shows full page templates assembled from those components.
- Use the **Theme** switch in the toolbar to preview any story in Light or Dark.
- The **Accessibility** tab checks each story for contrast and keyboard issues.

## Principles

1. Consistency over novelty
2. Content first
3. Accessible by default
4. Predictable behavior
5. One source of truth
